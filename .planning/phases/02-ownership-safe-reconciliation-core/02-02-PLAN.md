## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config secrets → AdGuard provider | Username/password input crosses into HTTP transport and must not leak through logs or errors. |
| AdGuard API → provider decoder | Remote JSON payloads are untrusted and must be decoded into the normalized visible-record shape only. |
| runtime factory → provider | Runtime must instantiate transport only, not accidentally move ownership policy into provider code. |
