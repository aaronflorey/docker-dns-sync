<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source snapshot → reconciler | Untrusted desired records cross into ownership policy and must be normalized before planning. |
| state snapshot → reconciler | Persisted ownership data controls destructive rights and must not be advanced on failed applies. |
| reconciler → output provider | Destructive remote mutations can tamper with operator-managed DNS if ownership checks are wrong. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-02 | Tampering | internal/runtime/reconcile_apply.go | mitigate | Apply remote operations before `state.Store.Save` and rebuild next snapshot only from successful mutations per D-04. |
| T-02-03 | Denial of Service | internal/runtime/reconcile_plan.go | mitigate | Detect duplicate visible keys early and return an ambiguity result that skips destructive actions per D-03 instead of looping or retrying blindly. |
| T-02-SC | Tampering | package installs | accept | No package-manager changes are part of this plan; package legitimacy gate is not applicable. |
</threat_model>
