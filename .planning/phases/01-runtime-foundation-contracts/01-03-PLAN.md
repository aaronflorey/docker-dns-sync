## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| runtime registry → provider constructors | Untrusted or mismatched provider types can break startup if construction is not centralized and validated. |
| source metadata → normalized contract types | Provider-specific identities must not weaken the immutable source-object contract. |

</threat_model>
