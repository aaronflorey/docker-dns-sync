## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| validated runtime config → state store | Operator-selected file paths control persisted ownership storage and must be handled safely. |
| runtime bootstrap → local filesystem | Persisted ownership data becomes the future mutation boundary, so torn writes or weak permissions are dangerous. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-10 | Tampering | internal/state/atomic_file.go | mitigate | Use temp file + fsync + rename writes and restrictive file permissions so crashes do not corrupt ownership state. |
| T-01-11 | Information Disclosure | internal/state/store.go | mitigate | Store only ownership metadata needed by later phases; keep secrets out of state snapshots entirely. |
| T-01-12 | Denial of Service | internal/runtime/app.go | mitigate | Fail startup if state store init, retry-policy parse, or provider construction fails; enter the run loop only after full bootstrap succeeds. |
| T-01-SC | Tampering | dependency surface | mitigate | Keep the final walking skeleton on already-audited dependencies; no new optional packages are introduced in this slice. |
</threat_model>
