# Security Policy

## Reporting a Vulnerability

Please do not open public issues for security-sensitive reports.

Send a report through GitHub Security Advisories for this repository if available, or contact the maintainer directly with:

- A description of the issue
- Affected versions or commit range
- Reproduction steps or a proof of concept
- Any suggested mitigation

I will acknowledge valid reports as quickly as possible and work on a fix before public disclosure.

## Supported Versions

Security fixes are best-effort for:

- The latest tagged release
- The current default branch
